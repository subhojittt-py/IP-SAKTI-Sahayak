# IP-SAKTI-Sahayak — Frontend

The frontend of **IP-SAKTI-Sahayak**, an AI-powered Intellectual Property and regulatory assistance platform.

It provides a user-friendly interface for:

- AI-powered IP-related questions
- Intellectual Property analysis
- Regulatory compliance checklists
- Jurisdiction comparison
- Access to trusted sources and references

---

## Tech Stack

- React
- Vite
- React Router
- JavaScript
- CSS
- REST API
